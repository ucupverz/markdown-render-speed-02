A self-contained, drop-in replacement for marked 18.1.3 that renders the same HTML byte for byte while running roughly 1.3x faster on the bounty's markdown corpus. The parser algorithm is unchanged; only the hot paths were rewritten to do less work per character.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
